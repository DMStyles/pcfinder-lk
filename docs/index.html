Why PCFinder LK?

⚡

Asynchronous Concurrency

All 12 scrapers fire in parallel with asyncio.gather(), returning unified multi-store results in 2–3 seconds.

🎯

Strict Relevance Filtering

Eliminates store search noise. Searching for a CPU won't leak monitors, power supplies, or RAM speed matches into your results.

🛡️

SQLite 1-Hour Caching

MD5-hashed queries with automated 1-hour TTL reduce scraping load on retailer websites and prevent IP throttling.

Deployment

Run PCFinder LK Locally

Recommended

Option 1: Docker Compose (Full-Stack)

1 Command 
git clone https://github.com/DMStyles/pcfinder-lk.git
cd pcfinder-lk
docker-compose up --build

Frontend opens at http://localhost:3000 · Backend API at http://localhost:8000/docs

Option 2: Standalone Local Setup

1. Backend (FastAPI)

cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

2. Frontend (Next.js)

cd frontend
npm install
npm run dev
