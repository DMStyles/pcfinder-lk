Developer Setup

Run Full-Stack Locally

Clone and launch the complete Next.js 14 frontend + FastAPI backend service.

Recommended

Docker Compose (Single Command)

docker-compose.yml 
git clone https://github.com/DMStyles/pcfinder-lk.git
cd pcfinder-lk
docker-compose up --build

Frontend on http://localhost:3000 · Backend API on http://localhost:8000/docs

Standalone Python + Node Setup

1. Backend (FastAPI)

cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

2. Frontend (Next.js 14)

cd frontend
npm install
npm run dev
